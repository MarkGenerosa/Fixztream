Install the companion helper

Chrome can't run PowerShell on its own. A small helper on your PC does it — set it up once:

Download helper.zip from GitHub
  1. Open the downloaded zip and click Extract all.
  2. Right-click install.ps1 → Run with PowerShell and approve the admin prompt. (Windows 11: under “Show more options”.)
  3. Come back here and press ↻.

Helper update available

New jobs need helper 2.0.0 — you have 1.0.0. Download it and run install.ps1 again; it replaces the old one.
